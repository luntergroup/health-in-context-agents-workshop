Find your way around

Type your request in the Message Copilot box. Use New chat in the left sidebar to start a fresh conversation. The Add and manage sources control beside the message box lets you add files when an exercise calls for them.

Choose a model or response mode

At the top of the chat, look for the dropdown labelled Auto. In the interface shown during preparation, it appears near the upper left of the conversation area. Open it to see the available choices:

  • Auto: Copilot automatically chooses how to respond. Microsoft describes this as routing based on the prompt.
  • Quick response: prioritizes a fast answer for straightforward questions.
  • Think deeper: allows more reasoning time and may be useful for complex analysis.
  • GPT (OpenAI): the menu also offers an OpenAI model choice.

The available choices and their location may differ by account or change over time. If you are unsure which option to use, ask the facilitator.

Learn more about model selection in Microsoft Copilot ↗.

How the workshop works

Each topic begins with a short introduction. You will then try an exercise and discuss the assistant’s choices and your experience with the group.

A useful habit

Inspect the assistant’s output and ask follow-up questions. Your own knowledge is an important part of the process.

For the first exercise

You can work directly in a standard Copilot chat. There are no files to upload and no custom agent to set up.
