STOP 04 / AGENTS & SKILLS

Give an assistant
reusable skills.

Create a Copilot agent and use it to work on an example grant proposal.

IN THIS STOP

Agents & skills

See the full workshop ↗

Objectives

  • Learn how to build an agent with skills in Microsoft Copilot.
  • Understand that agents are good at “changing representations” of content.

Read the slides for this session ↗

1. Download the materials

Download the two skills and the example grant proposal. The skill ZIP files are uploaded to the agent; the proposal is used in the chat.

Salary calculatorSkill package · ZIP↓Gantt chart makerSkill package · ZIP↓Example grant proposalPDF · project and budget information↓

2. Create the agent

Open Copilot. In the left sidebar, select Agents, then New agent. Agent Builder opens with a chat-like screen asking you to describe your agent.

Describe your agent

Send this short instruction to Agent Builder:

PROMPT FOR COPILOT

Your job is to help prepare grant applications.

You may be prompted to answer follow-up questions. Answer those. Wait for the builder to prepare a draft. It will open a Configure panel where you can review and customize the agent’s name, instructions, skills, and other settings.

Upload both skills

In the Skills section of the Configure panel, upload the two ZIP files you downloaded. Add them one at a time:

  1. Click the small dropdown arrow next to Add, then select Upload.
  2. Choose salary-calculator.zip and click Upload. Wait until the skill appears in the list.
  3. Repeat the same steps with make-gantt-chart.zip.
  4. Check that both salary-calculator and make-gantt-chart appear under Skills.

Create and open the agent

Click Create at the bottom of the configuration panel. When Copilot confirms that the agent has been created, choose Start chat. Your new agent is private to you unless you choose to share it.

Choose the workshop model

The selector at the top often starts on Auto, which is not enough for these tasks. Before every instruction, open it, expand GPT (OpenAI), and select GPT-5.6 Sol Think deeper. It can reset after each reply, so check it again before you continue. The available choices may differ by account; see Get started for more guidance.

Open the example grant proposal and attach it to the chat, or paste its contents into the message box. Then use the prompts below. The controls or labels may differ slightly between Copilot versions.

3. Calculate the personnel budget

PROMPT FOR COPILOT

Based on the attached project proposal, calculate the personnel budget for both positions according to the UMCG CAO: Postdoctoral Researcher: Scale A10, starting Step 11, annual step increment (periodiek) in August, 0.8 FTE. PhD Candidate: Scale PRO, starting Step 0, annual step increment in August, 1.0 FTE. Please calculate the costs, accounting for the 18.05% employer surcharge, and provide the individual and combined totals.

Check the result:

  • The calculation uses the supplied scales and steps across the 12-month appointment.
  • It accounts for the step increment on 1 August and applies the 18.05% employer surcharge.
Choose the workshop model again

The selector may have reset to Auto. Select GPT-5.6 Sol Think deeper before the next instruction.

Then try a follow-up:

PROMPT FOR COPILOT

What would the combined personnel budget be if we increase the postdoc from 0.8 FTE to 1.0 FTE?

Or:

PROMPT FOR COPILOT

If the funder provides a fixed total personnel budget of €150,000, how could we adjust the FTE of the postdoc to fit within this envelope?

4. Make a project timeline

Choose the workshop model again

The selector may have reset to Auto. Select GPT-5.6 Sol Think deeper before the next instruction.

PROMPT FOR COPILOT

Generate a Gantt chart in plain text SVG format from all work packages, tasks, and milestones using the skill. Do a quality assurance round, editing the SVG text as needed. Compress as a ZIP file for download.

Check the result:

  • The four work packages (WP1 to WP4) are laid out as chronological phases.
  • The chart shows the quarters from Q4 2026 to Q3 2027, with tasks and milestones marked.
Choose the workshop model again

The selector may have reset to Auto. Select GPT-5.6 Sol Think deeper before the next instruction.

Then try an adjustment:

PROMPT FOR COPILOT

How would the schedule shift if ethics approval for WP1 is delayed by 2 months?

Or:

PROMPT FOR COPILOT

Can you also generate clean SVG code for this Gantt chart so I can insert it directly into a presentation or webpage?

5. Discuss

  • Did the agent use the information in the proposal and the skills as expected?
  • Which calculations or timeline details could you verify?
  • What instructions or resources would make the agent more useful for your own work?
