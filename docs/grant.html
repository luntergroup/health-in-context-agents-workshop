1. Download the materials

Download the two skills and the synthetic proposal. The skill ZIP files are uploaded to the agent; the proposal is used in the chat.

2. Create the agent

Open Copilot. In the left sidebar, select Agents, then New agent. Agent Builder opens with a chat-like screen asking you to describe your agent.

Describe your agent

Send this short instruction to Agent Builder:

PROMPT FOR COPILOT

Your job is to help prepare grant applications.

Wait for the builder to prepare a draft. It will open a Configure panel where you can review and customize the agent’s name, instructions, skills, and other settings.

Upload both skills

In the Skills section of the Configure panel, upload the two ZIP files you downloaded. Add them one at a time:

  1. Click the small dropdown arrow next to Add, then select Upload.
  2. Choose salary-calculator.zip and click Upload. Wait until the skill appears in the list.
  3. Repeat the same steps with make-gantt-chart.zip.
  4. Check that both salary-calculator and make-gantt-chart appear under Skills.

Create and open the agent

Click Create at the bottom of the configuration panel. When Copilot confirms that the agent has been created, choose Start chat. Your new agent is private to you unless you choose to share it.

Open the synthetic proposal and attach it to the chat, or paste its contents into the message box. Then use the prompts below. The controls or labels may differ slightly between Copilot versions.

3. Calculate the personnel budget

PROMPT FOR COPILOT

Based on the attached project proposal, calculate the personnel budget for both positions according to the UMCG CAO: Postdoctoral Researcher: Scale A10, starting Step 11, annual step increment (periodiek) in August, 0.8 FTE. PhD Candidate: Scale PRO, starting Step 0, annual step increment in August, 1.0 FTE. Please calculate the costs, accounting for the 18.05% employer surcharge, and provide the individual and combined totals.

Check whether the assistant uses the appointment period, August step increments, FTEs, and surcharge. Then try a follow-up:

PROMPT FOR COPILOT

What would the combined personnel budget be if we increase the postdoc from 0.8 FTE to 1.0 FTE?

4. Make a project timeline

PROMPT FOR COPILOT

Using the Gantt chart skill, first show a table in the chat listing all work packages, tasks, start and end dates, and milestone due dates from the proposal. Then create a Gantt chart as a directly downloadable plain-text SVG file. Perform the quality checks specified in the skill, including parsing the SVG as XML and checking the grid, milestone dates, and rendering recipe. Correct any problems before providing the file.

Check the four work packages, their timing, and the milestones against the proposal. Ask for changes to the chart or explore how the schedule might shift if a task is delayed.

5. Discuss

  • Did the agent use the information in the proposal and the skills as expected?
  • Which calculations or timeline details could you verify?
  • What instructions or resources would make the agent more useful for your own work?
