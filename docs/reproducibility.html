STOP 03 / RESEARCH & REPRODUCIBILITY

Can we reproduce
a result?

Work with a published paper and data to recreate and extend a mortality-prediction analysis.

IN THIS STOP

Research & reproducibility

See the full workshop ↗
The scenario

Agogo and Mwambi (2025) studied all-cause mortality using NHANES 2009–2016 and linked public-use mortality data. Your task is to reproduce their logistic regression and explore extensions.

1. Get the materials

Open the research paper by Agogo and Mwambi (2025) ↗. Access to the full article may require an institutional subscription. Obtain the PDF through your institution if available, then download the prepared data below. Upload both files to a new Copilot chat.

NHANES dataZIP archive with .txt extension · about 18 MB↓

The data file has a .txt extension for upload, but it is a ZIP archive. It combines publicly available NHANES data ↗ with the CDC’s 2019 public-use linked mortality files ↗.

2. Reproduce the published model

Upload the paper and data to a new Copilot chat.

Choose the workshop model

In your Copilot chat, open the model selector at the top (often labelled Auto), expand GPT (OpenAI), and select GPT-5.6 Sol Think deeper before starting the exercise. The available choices may differ by account; see Get started for more guidance.

Then ask the assistant to reproduce the logistic regression and compare it with the paper.

PROMPT FOR COPILOT

Re-implement only the logistic regression from the attached paper. Use complete cases and the outcome “dead by 31 December 2019”. Where the description is ambiguous, explain your choices and choose the option that reproduces the published sample sizes. Compare AUC-ROC and AUC-PR with Table 3 for the training and test sets. Provide the code and explain your data preparation and modeling choices.

Look at the result

  • Do the sample sizes and performance measures match the paper?
  • Which details were ambiguous, and how did Copilot resolve them?
  • Can you follow the data preparation and check the code?

3. Extend the analysis

Continue in the same chat. Each step builds on the preceding one. Review the result and the assistant’s choices before moving to the next prompt.

A. Account for the observation window

Participants from later survey cycles have less potential follow-up time before the end of 2019.

PROMPT FOR COPILOT

Extend the logistic regression from Task 1 by adding potential follow-up time, measured in months from examination to 31 December 2019, as a predictor. Do not use recorded follow-up time as a predictor: for people who died, it represents time to death. Compare the new model with the original and explain your choices.

B. Try a survival model

A survival model can account for the time until death or censoring.

PROMPT FOR COPILOT

Fit a Cox model using time since examination. Use it to predict each person’s risk of death by 31 December 2019, and compare its performance with the logistic regression that includes potential follow-up time. Explain how you calculate individual risks.

C. Explore age

Consider whether the relationship between age and mortality is adequately represented by a straight line.

PROMPT FOR COPILOT

Add a quadratic age term to both the logistic regression and the Cox model from the preceding steps. Compare their performance and keep the better model. Explain how you made the comparison.

D. Include all participants

Now use the better model from the previous step without restricting the analysis to complete cases.

PROMPT FOR COPILOT

Using the better model from the previous step, drop the complete-case restriction. Set marital status to “not married” for those under 20, who were not asked; drop household income; impute all other missing values using MICE without using the outcome; and add missingness indicators except for marital status, using one indicator for variables that are always missing together. Evaluate on the full test set. Report AUC-ROC, AUC-PR, log loss, mean predicted risk, and the true event rate. Explain the data preparation and how the imputation is applied.

Review the extensions

  • Did Copilot distinguish potential follow-up time from recorded time to death?
  • How did the models and missing-data decisions change the results?
  • Are the predicted risks consistent with the observed event rate?

4. Discuss

  • Which details in the paper were ambiguous, and how did the assistant resolve them?
  • Did it correctly distinguish potential follow-up time from time to death?
  • How did the handling of missing data affect the analysis?
  • What would you check before trusting or sharing the results?
