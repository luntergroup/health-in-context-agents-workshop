STOP 02 / FIRST EXERCISE

Make the numbers
visible.

Explore sample size and statistical power with a graph, using only a prompt in Copilot.

IN THIS STOP

First exercise

See the full workshop ↗
The scenario

A team is planning a hypothetical randomized trial with a continuous outcome. It expects a standard deviation of 10 points but is uncertain about the treatment effect. Explore differences of 2, 3, and 4 points.

1. Generate a power graph

Start a new Copilot chat.

Choose the workshop model

In your Copilot chat, open the model selector at the top (often labelled Auto), expand GPT (OpenAI), and select GPT-5.6 Sol Think deeper before starting the exercise. The available choices may differ by account; see Get started for more guidance.

Then copy and send this prompt:

PROMPT FOR COPILOT

We are planning a two-arm randomized trial with equal group sizes and a continuous primary outcome. Assume independent, normally distributed outcomes and a standard deviation of 10 points in both groups. We plan to compare group means using a two-sided independent-samples t-test at a significance level of 0.05. Use simulation to estimate power for sample sizes from 20 to 500 participants per group and for true differences in group means of 2, 3, and 4 points. Create a graph with sample size per group on the x-axis and estimated power on the y-axis. Use a different color for each effect size and add a horizontal line at 80% power. Explain the assumptions, state how many simulated trials you used for each point, and provide the code and a downloadable graph.

Look at the result

  • What does 80% power mean here?
  • How does the required sample size change with the assumed effect?
  • Are the axes and assumptions clear? Is sample size per group or for the whole trial?
  • Are the simulation results smooth enough? What happens if you ask for more simulated trials?

2. Explore the assumptions

Choose one or more follow-up questions.

PROMPT FOR COPILOT

Approximately how many participants per group are needed for 80% power for each effect size? Also give the total for the trial. Explain how you estimated the crossing point from the simulation.

PROMPT FOR COPILOT

How does the graph change if the standard deviation is 12 rather than 10 points? Show the original and new results in a way that is easy to compare.

PROMPT FOR COPILOT

If 15% of recruited participants are expected to drop out before the outcome is measured, how many should we recruit per group for each effect size? Show the calculation and round up to whole participants.

For dropout, distinguish participants needed with outcome data from participants to recruit. This simple adjustment assumes 15% dropout in each group.

3. Validate a result

Compare one simulated result with an analytical calculation.

PROMPT FOR COPILOT

Check the simulated power for an effect of 3 points, a standard deviation of 10 points, and 175 participants per group against an analytical calculation for the same two-sided independent-samples t-test. Show both estimates, state the number of simulations, and give the simulation’s approximate 95% Monte Carlo uncertainty interval. Explain whether any difference is consistent with simulation uncertainty.

Analytical power should be approximately 80%. Simulation introduces random variation, so the two estimates need not match exactly. If they differ beyond the expected simulation uncertainty, ask the assistant to investigate its code and assumptions.

4. Discuss

  • Which assumptions had the greatest influence on sample size?
  • Which choices did you clarify or correct?
  • Could another researcher reproduce and check the graph?
  • What else would you need before planning a real study?
